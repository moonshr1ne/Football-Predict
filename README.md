# Barça Match Lab

Локальное приложение для прогноза матчей `FC Barcelona` в Ла Лиге и Лиге чемпионов. Пользователь вводит только соперника. Приложение само находит ближайший матч, дату, турнир, тур/стадию и домашнее поле.

## Что учитывается

- последние 10 матчей Барселоны и соперника;
- раздельная форма в Ла Лиге и ЛЧ;
- динамический Elo, домашнее поле, отдых и сила соперника;
- очные встречи с уменьшением веса матчей старше двух лет;
- владение, удары, удары в створ, угловые и фолы из протоколов ESPN;
- реальные формации последних матчей и подтвержденные составы;
- сила стартового состава относительно ядра предыдущих восьми игр;
- назначенный судья и его среднее число фолов по загруженным протоколам;
- предматчевые рыночные вероятности ESPN, только когда они опубликованы.

Модель выводит исход 1X2 и «Барселона не проиграет», один наиболее вероятный точный счет, ожидаемые голы и вероятности ТБ/ТМ, угловые, фолы, тактическое сравнение и рекомендуемую ставку при расчетной вероятности от 75%.

## Запуск

```powershell
python -m football_predictor.cli sync --force
python -m football_predictor.cli backtest --force
python -m football_predictor.cli serve --port 8765
```

Открыть: [http://127.0.0.1:8765/](http://127.0.0.1:8765/)

Прогноз из терминала:

```powershell
python -m football_predictor.cli predict "Реал Мадрид"
```

## Защита от подсматривания

Признаки каждого обучающего примера строятся только из матчей, стартовавших раньше него. На один ESPN `fixture_id` сохраняется ровно один неизменяемый предматчевый снимок. После стартового свистка приложение показывает этот снимок и фактический результат; если снимка не было, прогноз задним числом не создается.

`data/barcelona_backtest.json` содержит walk-forward метрики. Это фактическая проверка, а не обещание гарантированной доходности: точный счет и спортивные события принципиально не могут иметь гарантированную точность.

## Данные

Источник: ESPN scoreboards и match summaries для `esp.1` и `uefa.champions`. Первичная синхронизация загружает четыре сезона. Затем сервер обновляет расписание, протоколы и сохраненные прогнозы автоматически раз в час.
